# Some short atomic rules to remember about this module because it has some complexity

- Transcript and structured notes are two panes. Each scrolls on its own. Never one shared page height.
- Light grey = every quote extracted (not only in focus)
- Dark grey = the fact or complément the user has focused or clicked
    - it should apply to the quoted text
    - but also to the "fact" in structured extraced text so the user links both
    - but also if i click the quoted text it should also work to highlight the couple
- If that span is already in view, a click must not scroll. If it is off-screen, scroll it to the middle of the pane — not flush to the bottom.
- Compléments: three groups in this order — Arrêt, Maintien, Ajout — inferred from the current recs, never picked. Catalogue search sits under Ajout. Retirer drops a product from the note (a current rec then appears under Arrêt). Paint the product name only, first occurrence. Not the surrounding sentence.
- Motif / anamnèse / hygiène / suivi: no + or – buttons. Blank last line adds. Backspace on an empty line removes. Arrows move between lines.
