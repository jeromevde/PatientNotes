JSON in this folder is the mock database. No comments inside the files (JSON forbids it).

- `patient.json` — the dossier (identity, history, current recs, labs)
- `products.json` — mini-catalog; notes may only use these product ids
- `transcript.json` — free-text consultation; input to the note-taker
- `notes.json` — example structured notes if there is no API key
- `assignment.md` / `context_simplycure.md` — the case brief, not used by the app
